# Look from Above Component References

`Look from Above: Satellite-Guided Generative Mapping for Robust Pseudo-Labeling` currently has no codebase. The user has confirmed that implementation should use the paper's paradigm plus public codebases that it builds on or compares against.

This directory is reserved for public component-level repositories that the paper cites or directly builds around. These repositories are useful code references, but they are not the official implementation of the Look from Above submission.

## Planned Component Refs

- `PseudoMapTrainer`: pseudo-label generation from unlabeled sensor data, Gaussian splatting, semantic reconstruction, and mask-aware assignment.
- `MapTR`: structured vectorized HD map construction and downstream map head reference.
